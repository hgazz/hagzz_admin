# سجل تدقيق الأدمن

المسار: `/admin/audit-logs` (مع بادئة اللغة عند تفعيلها)، ورابط «سجل تدقيق الأدمن» تحت إدارة المنصة. متاح لحسابات admin المصادق عليها؛ لا يوجد حاليًا نظام أدوار منفصل داخل الأدمن، لذلك تستخدم الصفحة صلاحية الدخول الحالية نفسها. لا توجد واجهات لتعديل السجلات أو حذفها.

يسجل الوسيط طلبات POST/PUT/PATCH/DELETE للمسارات المسماة `admin.*`، بالإضافة إلى الدخول الناجح والخروج. يحتفظ بمعرّف الموظف واسمه وقت العملية، اسم المسار والطريقة، المعرّفات الرقمية في معاملات المسار أو حقلي id/ids (بحد 500 عنصر لكل حقل)، حالة HTTP ونتيجة الطلب، IP والتوقيت. لا توجد علاقة حذف متسلسل تربط السجل بحساب الموظف، حتى يبقى التاريخ بعد حذف الحساب.

لا تُحفظ أجسام الطلبات أو قيم الحقول أو كلمات المرور أو الكوكيز أو رموز الدخول أو الاستعلامات أو الملفات. أسماء الموظفين تُعرض باستخدام escaping. تعرض الصفحة 25 سجلًا لكل صفحة، بترتيب الأحدث، وتتيح تصفية الموظف واسم المسار المطابق والنتيجة والفترة.

## حدود التغطية

هذا سجل لطلبات إدارة المنصة، وليس تاريخًا لكل صف في قاعدة البيانات. النتيجة «مكتمل» تعني استجابة أقل من 400 دون استثناء أو أخطاء validation/flash معروفة؛ لا تثبت تغيير البيانات فعليًا، خصوصًا إذا كان controller يعيد رسالة خطأ داخل JSON بحالة 200. لا تُحفظ قيم قبل/بعد، ولا تسجل أعمال CLI أو التغييرات المباشرة في SQL أو خدمات API/الشركاء الأخرى. لا تسجل القراءات العادية أو محاولات دخول الضيوف الفاشلة أو الأخطاء التي تقع قبل الوسيط، مثل CSRF. سجل أنشطة الشريك الموجود في صفحة تفاصيله منفصل ولم يُعدَّل.

يبدأ التسجيل بعد النشر والترحيل، دون إنشاء تاريخ سابق. التوقيت المعروض يتضمن منطقة زمن التطبيق. إذا تعطل تخزين السجل، يُكتب تنبيه `critical` باسم `Admin audit write failed` ويُبلّغ الاستثناء، مع الاحتفاظ باستجابة العملية الأصلية لتجنب إعادة دفع ناجح بسبب رسالة فشل تخص السجل. ينبغي مراقبة هذا التنبيه؛ السجل ليس مخزنًا خارجيًا مقاومًا للتعديل من مدير قاعدة البيانات.

## النشر

بعد جلب master وبناء وتشغيل خدمة admin، يلزم تنفيذ الترحيل الجديد:

```bash
docker compose exec -T -w /var/www/html admin php artisan migrate --force
docker compose exec -T -w /var/www/html admin php artisan route:cache
docker compose exec -T -w /var/www/html admin php artisan view:clear
```

لا تُشغّل rollback لهذا الترحيل في الإنتاج إلا إذا كان حذف السجل بالكامل مقصودًا. لا تُجرب عمليات حذف أو تحصيل على بيانات عميل حقيقية للتحقق؛ استخدم حسابًا وبيانات اختبار.

## التحقق المحلي

اختبارات SQLite منفصلة عن بيانات التشغيل تغطي: هوية المنفذ ومعرّفات السجلات، عدم تخزين الأسرار، استبعاد القراءات، validation/authorization، الدخول والخروج، حجب الضيوف، تصفية الصفحة وترميز HTML، حدود التاريخ، الترحيل والتراجع، والتنبيه عند تعطل التخزين مع إبقاء الاستجابة الأصلية.
