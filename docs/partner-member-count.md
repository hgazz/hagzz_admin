# عدد اللاعبين والأعضاء في جدول الشركاء

أُضيف عمود «عدد اللاعبين / الأعضاء» بعد اسم الشريك في جدول الأكاديميات/الشركاء بالأدمن، مع دعم العربية والإنجليزية والترتيب العددي والتصدير.

العدد هو عدد ملفات `academy_students` المرتبطة مباشرة بالشريك عبر `academy_id`، ويشمل الملفات غير النشطة. لا يعتمد على عدد الاشتراكات السارية أو الحجوزات أو مجموعات التدريب، ولا يشمل موظفي الشريك أو مستخدمي التطبيق الذين لم تُنشأ لهم ملفات لدى الشريك. الشريك بلا ملفات يظهر له صفر. عدد أعضاء المنشأة ليس عدد عملاء حجوزات الملاعب.

يُحسب العدد باستعلام تجميعي ضمن طلب الجدول، ولا يُخزّن في عمود قاعدة بيانات قابل للتقادم. لا توجد ترحيلات جديدة مطلوبة. تبقى بيانات الصفوف منفصلة بحسب الشريك الذي يملك الملفات.

نجحت اختبارات الميزة الستة: العدد لكل نوع نشاط، وصفر للمنشآت الفارغة، وعدم احتساب الحجوزات المكررة، وإضافة وحذف عضو، والترتيب العددي عبر طلب AJAX الفعلي، والعناوين العربية/الإنجليزية، والتصدير. اختبار الاستعلامات يؤكد عدم إضافة استعلام عدّ مستقل لكل صف.

هذه الإضافة في مستودع `hagzz_admin`، وتحتاج نشر خدمة الأدمن؛ نشر خدمة `academy` وحده لا يحدّث شاشة الأدمن. تنسيقات واجهة الشركاء مستقلة عن تنسيقات الأدمن. تصحيح حالات السداد السابقة يظهر في البيانات المشتركة عند اتصال التطبيقين بقاعدة الإنتاج نفسها.
